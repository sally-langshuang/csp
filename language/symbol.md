## 记忆要点

### 1. 后缀 > 前缀 > 二元 > 三目 > 赋值 > 逗号

a++  >  ++a  >  a+b  >  a?b:c  >  a=b  >  a,b

### 2. 单目运算符里 `&`、`*`、`!`、`~`、`++`、`--` 同优先级

它们都是右结合，所以：

*p++      // *(p++)     先 p++ 再解引用
&buf[0]   // &(buf[0])  先 [] 再 &

### 3. `[]` `()` `.` `->` 属于“后缀”类，优先级最高

所以：

a.b[0]      // (a.b)[0]
f(x)[0]     // (f(x))[0]
*p[0]       // *(p[0])   注意不是 (*p)[0]
&buf[0]     // &(buf[0])

### 4. 常见陷阱速查

| 表达式 | 实际解析 | 说明 |
|--------|----------|------|
| `*p++` | `*(p++)` | 先自增指针，再取值 |
| `(*p)++` | 取 `*p` 后自增其值 | 两者不同 |
| `&buf[0]` | `&(buf[0])` | 先下标再取地址 |
| `&buf` | 指向整个数组的指针 | 类型 `int(*)[N]` |
| `a = b = c` | `a = (b = c)` | 赋值右结合 |
| `a ? b : c ? d : e` | `a ? b : (c ? d : e)` | 三目右结合 |
| `cout << a + b` | `cout << (a + b)` | `+` 高于 `<<` |
| `a & b == c` | `a & (b == c)` | `==` 高于 `&`，易错！ |
| `a << b + c` | `a << (b + c)` | `+` 高于 `<<` |

---

## 最实用的三条规则

1. `[]` `()` `.` `->` 最高，见到它们先算。
2. 单目 `&` `*` `++` `--` 次高，且右结合。
3. 不确定就加括号，可读性永远优先于炫技。
