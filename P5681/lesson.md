# 第一部分：先认识 C++

## 0. 程序是怎么跑起来的？

你写的代码，电脑其实**看不懂**。电脑只认识 0 和 1。

所以中间需要一个翻译官，叫**编译器**（我们用的这个叫 `g++`）：

```
你写的 main.cc  ──[编译器 g++ 翻译]──→  main.exe  ──[双击运行]──→  屏幕上出结果
   （人看的）                          （电脑看的）
```

所以写程序永远是两步：**先编译，再运行**。

在 VS Code 里，按一下 **F5** 就会自动帮你做完这两步。如果代码写错了，编译这一步就会失败，会有红字报错——**这是好事**，说明电脑在提醒你哪里写错了。

> 💡 新手看到报错别慌。报错不是"你很笨"，是"这里有个字打错了"。
> 老手每天也要看几十次报错，这是编程的日常。

## 1. 你的第一个程序

新建一个文件 `hello.cc`，一字不差地敲进去（**不要复制粘贴**）：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello!" << endl;
    return 0;
}
```

按 F5 运行，屏幕上会出现：

```
Hello!
```

**恭喜，你写出人生第一个 C++ 程序了。** 现在我们把它拆开，看每一行到底在干嘛。

---

## 2. 骨架解剖：这几行分别是什么

### 第 1 行：`#include <bits/stdc++.h>`

**人话翻译**："把工具箱搬进来。"

C++ 自己只会很少的事，像"输出文字"这种功能都放在工具箱里。这一行的意思是**把所有工具箱一次性搬进来**，这样后面想用什么都有。

现在你只要知道：**每个程序第一行都写它**，照抄就行。

### 第 2 行：`using namespace std;`

**人话翻译**："工具箱打开，东西直接拿。"

不写它的话，后面每次用 `cout` 都得写成 `std::cout`，很麻烦。

同样：**照抄，每个程序都写**。

### 第 4 行：`int main() {`

**人话翻译**："主程序从这里开始。"

`main` 是"主要的"意思。电脑运行程序时，就是从 `main` 开始一行一行往下执行的。

**每个 C++ 程序有且只有一个 `main`**，你的代码都要写在它的大括号里面。

### 大括号 `{ }`

`{` 表示"开始"，`}` 表示"结束"，它俩必须**成对出现**。

`main() {` 后面的所有代码，一直到对应的 `}`，都属于 main 这个"房间"里的东西。

### 第 6 行：`return 0;`

**人话翻译**："报告，程序正常结束。"

`0` 在这里代表"一切正常"。写在 `main` 的最后，**照抄就行**。

### 那个分号 `;`

**每一句代码的末尾都要有分号**，就像写中文句子末尾要有句号。

```cpp
cout << "Hello!" << endl;     ← 有分号 ✓
return 0;                     ← 有分号 ✓
```

漏了分号是新手第一大错误。编译器会报错，但报错位置常常指向**下一行**，所以找不到问题时，先看看上一行的分号。

⚠️ 注意：`#include` 那行和 `int main() {` 那行**不用**分号。规律是"一句完整的命令"才要分号。

### 缩进（前面空的那几格）

```cpp
int main() {
    cout << "Hello!" << endl;    ← 前面空了 4 格
    return 0;                    ← 前面空了 4 格
}
```

空格是给**人**看的，表示"这些代码住在 main 这个房间里"。不缩进程序照样能跑，但代码会变得像一团浆糊，自己都看不懂。

**从第一天起就养成缩进的习惯。** 在 VS Code 里按 `Tab` 键就能缩进。

### 注释 `//`

```cpp
cout << "Hello!" << endl;   // 这后面的字电脑完全不看
```

`//` 后面的内容电脑会直接跳过，是**写给人看的备注**。

用来提醒自己"这行是干嘛的"，非常有用。

> ✋ **动手试试**
> 1. 把 `Hello!` 改成你的名字，运行看看
> 2. **故意**删掉一个分号，运行，看看报什么错（认识报错长什么样很重要）
> 3. 把分号加回来，确认又能跑了

## 3. 让程序说话：`cout`

```cpp
cout << "Hello!" << endl;
```

拆成三块看：

| 部分 | 意思 |
|---|---|
| `cout` | 屏幕（**c**haracter **out**put，字符输出） |
| `<<` | 箭头指向 `cout`，表示**数据流向屏幕** |
| `endl` | 换行（**end** **l**ine，这一行结束） |

### 输出文字要加双引号

```cpp
cout << "Alice" << endl;    // 屏幕显示：Alice
cout << 25 << endl;         // 屏幕显示：25
```

规律：
- **文字**要用**英文双引号** `" "` 包起来
- **数字**直接写，不用引号

### 可以连着输出好几样

```cpp
cout << "面积是 " << 25 << endl;    // 屏幕显示：面积是 25
```

一个 `<<` 接一样东西，想接几个都行。

> ✋ **动手试试**：让程序输出 `我今年 10 岁`（把 10 当数字输出，其余当文字）。

## 4. 盒子：变量

程序要记住数字，就得有地方装。这个"地方"叫**变量**，你可以想成**贴了名字的盒子**。

### 造一个盒子

```cpp
int a;
```

- `int` 是盒子的**型号**（integer = 整数），这种盒子只能装整数
- `a` 是盒子的**名字**，你自己起

一次造好几个：

```cpp
int a, b, c;      // 一口气造三个盒子，逗号隔开
```

### 往盒子里装东西：`=`

```cpp
a = 5;      // 把 5 装进 a 这个盒子
```

⚠️ **超级重要**：这里的 `=` **不是数学里的"等于"**，它是一个**搬运动作**——"把右边的东西装进左边的盒子"。

所以下面这行在 C++ 里完全合法，在数学里却荒谬：

```cpp
a = a + 1;    // 把「a 现在的值加 1」装回 a  →  a 变大了 1
```

### 造盒子的同时就装东西

```cpp
int a = 5;    // 造一个叫 a 的盒子，同时装进 5
```

### 盒子里的东西可以拿出来用

```cpp
int a = 5;
cout << a << endl;      // 屏幕显示：5
```

注意 `a` **没有引号**。有引号是文字，没引号是盒子里的值：

```cpp
cout << "a" << endl;    // 屏幕显示：a     ← 字母 a 本身
cout << a << endl;      // 屏幕显示：5     ← 盒子 a 里装的东西
```

这个区别一定要分清。

> ✋ **动手试试**
> ```cpp
> int x = 3;
> int y = 7;
> cout << x << endl;
> cout << y << endl;
> x = 100;              // 把 x 里的东西换掉
> cout << x << endl;    // 猜猜显示什么？
> ```
> 先猜，再运行验证。

## 5. 让程序听话：`cin`

前面的程序，数字都是我们自己写死在代码里的。但做题时，数字是**别人给你的**（题目叫"输入"）。

```cpp
int a;
cin >> a;      // 等着你从键盘输入一个数，装进 a
```

| 部分 | 意思 |
|---|---|
| `cin` | 键盘（**c**haracter **in**put，字符输入） |
| `>>` | 箭头指向 `a`，表示**数据从键盘流向盒子** |

**记忆技巧**：`>>` 和 `<<` 的箭头方向，永远指向数据要去的地方。

```cpp
cin  >> a;              // 数据 → 盒子     （箭头指向 a）
cout << a << endl;      // 数据 → 屏幕     （箭头指向 cout）
```

### 一次读好几个

```cpp
int a, b, c;
cin >> a >> b >> c;     // 依次读三个数
```

输入时三个数可以用空格隔开写在一行：`5 4 6`，也可以每个一行，程序都认。

> ✋ **动手试试**：写个程序，读入一个数，然后输出它。
> ```cpp
> #include <bits/stdc++.h>
> using namespace std;
> int main() {
>     int n;
>     cin >> n;
>     cout << "你输入的是 " << n << endl;
>     return 0;
> }
> ```
> 运行后会弹出一个黑窗口等你输入，敲个数字按回车。

## 6. 算术：加减乘除

```cpp
int a = 7, b = 3;
cout << a + b << endl;    // 10   加
cout << a - b << endl;    // 4    减
cout << a * b << endl;    // 21   乘  ← 键盘上没有 ×，用星号
cout << a / b << endl;    // 2    除  ← 注意！不是 2.33
cout << a % b << endl;    // 1    取余数（7÷3 商2余1）
```

两个要特别注意的：

- **乘号是 `*`**，不是 `×`，也不是 `x`
- **整数相除会把小数部分直接扔掉**：`7 / 3` 得 `2`，不是 2.33。这个坑以后会遇到，先记住

### 算完要存起来

```cpp
int a = 5;
int S;
S = a * a;             // 算出 5×5=25，装进 S
cout << S << endl;     // 显示：25
```

> ✋ **动手试试**：读入一个数，输出它的**平方**（自己乘自己）。

## 7. 做选择：`if` 和 `else`

到目前为止，程序都是从上往下一行行执行。但有时候需要**分情况**。

```cpp
if (a > b) {
    cout << "a 大" << endl;
} else {
    cout << "b 大或者一样大" << endl;
}
```

念出来就是：**如果**（if）括号里的话成立，就做第一个大括号里的事；**否则**（else）做第二个大括号里的事。

**两条路只会走一条**，绝不会都走。

### 比较用的符号

| 符号 | 意思 | 例子 |
|---|---|---|
| `>` | 大于 | `a > b` |
| `<` | 小于 | `a < b` |
| `>=` | 大于或等于 | `a >= b` |
| `<=` | 小于或等于 | `a <= b` |
| `==` | **等于** | `a == b` |
| `!=` | 不等于 | `a != b` |

⚠️ **最容易搞混的一个**：判断"相等"要用**两个等号 `==`**！

因为一个等号 `=` 已经被"搬东西进盒子"占用了。这是新手最经典的错误之一。

```cpp
if (a == b)     // ✓ 判断 a 和 b 是不是相等
if (a = b)      // ✗ 这是把 b 搬进 a，不是判断！
```

### `else` 可以不写

```cpp
if (a > b) {
    cout << "a 大" << endl;
}
// 没有 else，条件不成立就什么都不做，继续往下执行
```

> ✋ **动手试试**：读入两个数，输出较大的那个。

## 8. 小结：所有入门题都是三段式

学到这里，语法就够用了。请记住这个万能框架：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 第 1 段：造盒子 + 输入
    int a;
    cin >> a;

    // 第 2 段：计算

    // 第 3 段：输出
    cout << ... << endl;

    return 0;
}
```

**输入 → 计算 → 输出**。90% 的入门题都逃不出这个结构。

现在，我们用它来解决今天的题目。

# 第二部分：解决 P5681「面积」

## 9. 先读懂题目在问什么

题目一大堆字，其实就一件事：

- Alice 有一个**正方形**，边长是 `a`
- Bob 有一个**长方形**，长是 `b`，宽是 `c`
- 问：**谁的面积大？**
- 正方形大 → 输出 `Alice`；否则 → 输出 `Bob`

用你三年级学过的公式：

```
正方形面积 = 边长 × 边长      →  S1 = a * a
长方形面积 = 长   × 宽        →  S2 = b * c
```

数学部分就这么简单。这道题真正的难点在第 12 节，先别急。

> ✋ **停一下想想**：题目说"若正方形面积大则输出 Alice，**否则**输出 Bob"。
> 那如果两个面积**一样大**呢？
>
> <details><summary>想好了再点开</summary>
>
> 一样大**不属于**"正方形面积大"，所以走"否则"这条路 → 输出 **Bob**。
>
> 所以代码里要写 `if (S1 > S2)`，**不能**写 `>=`。这个细节会坑掉很多人。
> </details>

---

## 10. 先别碰电脑，用铅笔算一遍

写代码之前，永远先手算样例。手算都算不对，说明题没读懂。

**样例 1：输入 `5 4 6`**

```
S1 = 5 × 5 = 25
S2 = 4 × 6 = 24
25 > 24  →  正方形大  →  输出 Alice   ✓ 和题目答案一致
```

**样例 2：输入 `7 5 10`**

```
S1 = 7 × 7  = 49
S2 = 5 × 10 = 50
49 < 50  →  正方形不大  →  输出 Bob    ✓ 对上了
```

思路验证通过，现在开始写代码。

---

## 11. 套三段式，一段一段填

**第 1 段：造盒子 + 输入**

题目说"仅一行三个正整数 a, b, c"，所以：

```cpp
int a, b, c;
cin >> a >> b >> c;
```

**第 2 段：计算**

```cpp
int S1, S2;
S1 = a * a;        // 正方形面积
S2 = b * c;        // 长方形面积
```

**第 3 段：判断 + 输出**

```cpp
if (S1 > S2) {
    cout << "Alice" << endl;
} else {
    cout << "Bob" << endl;
}
```

拼起来就是完整程序。

⚠️ 输出的单词必须**一模一样**：`Alice`、`Bob` 首字母大写。写成 `alice`、`BOB`、`Alise` 全算错，评测机一个字母都不通融。

> ✋ **动手试试**：现在合上讲义，自己把这个程序完整写出来，用两个样例试试。
> 写完了再看第 12 节 —— 因为你写的这份，**大概率只能得 80 分**。

---

## 12. 【本题最大的坑】盒子太小，会把数装坏

如果你刚才写的是 `int S1, S2;`，那么样例能过，交上去**只有 80 分**。为什么？

### 看题目最后的「数据范围」

```
对于 100% 的数据，1 ≤ a, b, c ≤ 10^9
```

`10^9` 就是 **10 亿**。也就是说正方形边长最大能到 10 亿。那面积是多少？

```
10亿 × 10亿 = 1000000000000000000   （1 后面 18 个 0，读作 100 亿亿）
```

### 而 `int` 盒子最大只装得下 21 亿

```
int  的上限 = 2147483647          （大约 21 亿）
```

100 亿亿 硬往 21 亿的盒子里塞——装不下。

**可怕的是：装不下不会报错，而是把数字弄坏。** 我真跑了一遍给你看：

| 算式 | `int` 算出来 | 正确答案 |
|---|---|---|
| 100000 × 100000 | `1410065408` ❌ | 10000000000 |
| 10亿 × 10亿 | `-1486618624` ❌❌ | 1000000000000000000 |

看第二行——**算出了负数**。面积怎么可能是负数？这就是"盒子装坏了"的样子。

这个现象叫**溢出**（像倒水，杯子满了会溢出来洒掉）。

### 解决办法：换个大盒子 `long long`

```
long long 的上限 = 9223372036854775807   （大约 922 亿亿）
```

922 亿亿 > 100 亿亿 ✓ 装得下！

用法和 `int` 一模一样，就是型号名字长一点：

```cpp
long long a, b, c;      // 三个输入的数也一起换成大盒子，最省心
long long S1, S2;
```

> 💡 **这条经验能用一辈子**：
> 做题先看数据范围。**只要算出来的结果可能超过 21 亿，就无脑用 `long long`。**
> `long long` 除了多打几个字母，没有任何坏处。这道题考的就是这一个知识点。

---

## 13. 完整代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    long long a, b, c;      // 用大盒子，防止面积溢出
    long long S1, S2;       // S1 = 正方形面积，S2 = 长方形面积

    cin >> a >> b >> c;     // 第 1 段：输入

    S1 = a * a;             // 第 2 段：计算
    S2 = b * c;

    if (S1 > S2) {          // 第 3 段：判断并输出
        cout << "Alice" << endl;
    } else {
        cout << "Bob" << endl;
    }

    return 0;               // 程序正常结束
}
```

一共 11 行有效代码。**请自己动手敲一遍，不要复制粘贴**——手指的记忆比眼睛可靠得多。

## 15. 交题前检查清单

每一条都是真会扣分的坑，逐条对照：

- [ ] 面积用的是 `long long`，不是 `int`
- [ ] 比较用 `>`，不是 `>=`（相等时要输出 Bob）
- [ ] `Alice`、`Bob` 首字母大写，拼写正确
- [ ] 文字用**英文双引号** `"`，不是中文引号 `“ ”`
- [ ] 每句末尾有**英文分号** `;`
- [ ] 括号是**英文括号** `()` `{}`，不是中文括号 `（）`
- [ ] 大括号 `{` `}` 成对，没有多也没有少
- [ ] 两个样例都亲自跑过，输出和题目一致

> 💡 **中英文标点是新手第一大报错来源。** 编译器一看见中文标点就罢工，
> 而且报错位置常常和真正出问题的地方差好几行，特别难找。
> **写代码时一定切到英文输入法。**

## 附：给讲课大人的备课要点

学生可以跳过这一节。

**课时建议**：第一部分（第 0～8 节语法）和第二部分（第 9～16 节做题）**分两次课**。一次讲完信息量太大，孩子会消化不了。

**第一部分的关键**：不要追求讲全，只讲这道题用得上的。`for` 循环、数组、函数**一律不提**。孩子第一次接触，每多一个概念就多一分挫败感。让他先体验"我能让电脑听我的话"这件事的乐趣。

**第二部分的核心只有一个**：`int` 会溢出，要用 `long long`。其余都是铺垫。

**建议的教学节奏（重要）**：

1. 让孩子用 `int` 写，**故意不提醒**
2. 提交，拿 80 分
3. 让他自己去题目的「数据范围」里找为什么丢了 20 分
4. 再讲溢出，改 `long long`，重新提交拿 100 分

**为什么要故意让他先错**：先踩坑再讲解，印象比直接告知深得多。这 20 分的教训，比讲十遍"注意溢出"都管用。

**关于 `1ll * a * a` 这种写法**：仓库里 `main.cc` 用的是它（`a b c` 保留 `int`，靠 `1ll *` 把计算提升到 long long）。更省内存，是竞赛选手的常用技巧，但对初学者**先别讲**——多一个知识点就多一个出错的地方。等"看数据范围 → 选类型"的习惯养熟了，再作进阶补充。

**关于 `scanf` 和 `cin`**：`main.cc` 用的是 `scanf("%d%d%d", &a, &b, &c)`。讲义统一用 `cin >>`，因为它少了 `%d` 格式符和 `&` 取地址两个记忆负担，对零基础更友好。等孩子熟练了、开始关心读入速度时再引入 `scanf`。

**关于 30%/80%/100% 的数据范围**：可以顺带解释"部分分"——想不出满分做法时，先拿部分分也是好成绩。这对建立信心很有用。
